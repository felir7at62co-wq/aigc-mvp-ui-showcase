# 剧本拖拽上传框设计

## 目标

移除浏览器原生“选择文件”按钮，将剧本上传改为整块可点击、可拖拽的自定义输入框。

## 交互

- 未选择文件时显示“点击或拖拽剧本文件到这里”和格式提示。
- 点击上传框通过隐藏的原生文件输入打开系统文件选择器。
- 拖入 `.txt` 或 `.docx` 文件时完成选择，并沿用现有的项目名称自动提取逻辑。
- 选择成功后显示文件名；拖拽悬停时高亮边框。
- 其他格式不进入表单，并在现有表单错误区域提示仅支持 `.txt`、`.docx`。

## 实现边界

新增独立 `ScriptFileDropzone` 组件负责文件交互；`ProjectsPage` 继续负责项目名称、表单状态和提交，不修改 API。

## 验证

页面测试覆盖点击区域、拖拽选择、文件名展示、自动命名和非法格式提示；随后运行完整测试、构建和浏览器可视化检查。
