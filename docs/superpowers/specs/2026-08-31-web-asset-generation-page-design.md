# Web 资产生成页设计

## 目标

修正项目生产阶段顺序，并把资产生成从项目总览中的任务按钮改为独立的可操作页面。用户导入剧本创建项目后，直接进入资产生成页；视频生成继续使用已完成的一体化工作台。

## 用户流程

1. 创建项目并导入剧本。
2. 系统完成剧本导入，进入资产生成页。
3. 用户在角色、场景、道具三个标签中管理并生成资产。
4. 用户进入视频生成页完成镜头脚本、资产匹配、视频生成和轨道编辑。

项目总览中的生产阶段固定按“剧本导入、资产生成、视频生成”排序，不依赖后端对象字段顺序。

## 页面结构

资产生成页包括：

- 页面标题、说明和总体任务状态。
- 操作栏：重新提取、导入自定义 TXT、编辑提取模板、生成选中资产、停止、刷新、打开目录。
- 角色、场景、道具三个标签页。
- 当前类别统计、全选、取消全选、智能导入图片。
- 卡片网格：第一张为添加资产，其余显示资产图片、名称、别名、出场集数和提示词。
- 卡片支持选中、编辑、删除、上传/替换图片；批量生成只提交当前类别选中的资产名称。

浏览器不能直接打开 Windows 文件夹，“打开目录”使用后端受控接口打开当前项目资产目录；失败时显示明确错误。

## 数据与接口

- `GET /api/projects/<name>/assets`：按角色、场景、道具返回提示词记录与图片路径的并集。
- 继续使用现有资产新增、编辑、删除接口。
- 新增图片上传接口，保存到受控的项目资产类别目录。
- 资产生成继续提交现有 `asset` 任务，并通过 options 传递当前类别和选中名称；后端生成操作据此过滤，未提供过滤条件时保持原有全量行为。
- 重新提取暂复用现有提示词任务入口；TXT 导入和模板编辑在后端能力不可用时提供明确的未配置提示，不伪造成功状态。

## 错误处理与兼容

- 资产列表由提示词文件和图片目录合并，兼容只有文本、只有图片和两者都有的旧项目。
- 非法类别、非法文件名、非图片上传和项目不存在均返回 4xx。
- 新增、编辑、删除或上传成功后刷新当前类别。
- 任务失败通过页面消息和任务状态展示，不清空已有资产。
