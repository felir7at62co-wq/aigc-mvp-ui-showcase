# 明确任务：视频管线与项目创建改版

## 范围

本轮不实现 Agent。只处理用户明确指定的页面、创建项目、视频生成、图片生成与 RunningHub 清理。

## 导航

- 点击“视频生成”进入项目第一集的视频工作台，不再停留在项目总览。
- 点击“设置”进入独立项目设置页，不再在总览中插入占位卡片。
- 项目总览保留状态摘要，但不作为视频生成或设置的目标页面。

## 创建项目

- 选择剧本文件后，项目名称自动使用文件名（去扩展名），用户仍可修改。
- 集数由后端分集解析自动识别，不要求用户输入。
- 表单仅显示：剧本文件、项目名称、视频尺寸、清晰度、镜头脚本公共前缀。
- 隐藏固定项：视频模型 `seedance-2-0-official`、生成方式 `reference`、单次生成时长 15 秒。
- 清晰度默认 720p；尺寸默认 9:16；公共前缀可空。
- 配置保存在项目目录，旧的仅上传名称和剧本请求仍可创建并使用默认值。

## 模型接入

- 统一使用环境变量提供的云映 API Base URL 与 API Key，不把密钥写进源码、项目配置或前端。
- 视频调用 `POST /v1/videos/generations`，模型默认 `seedance-2-0-official`，轮询 `GET /v1/tasks/{task_id}`。
- 图片调用 `POST /v1/images/generations`，模型默认 `gpt-image-2-official`。
- 参考图片先通过 `POST /v1/files` 上传，视频请求使用返回的公网 URL。
- 删除所有运行路径中的 RunningHub 客户端、工作流 ID 与工作流 JSON 依赖。

## 15 秒批次与切镜头

- 将连续镜头按目标时长装入最多 15 秒的子任务；镜头未声明时长时默认 5 秒。
- 每个子任务一次生成 15 秒视频，提示词包含公共前缀和该批次所有完整镜头脚本。
- 生成完成后使用内置 FFmpeg 按镜头累计时长切割，输出继续使用 `web_video/<集>/<镜头>.mp4`。
- 用户选择单镜头重生成时，只建立包含该镜头的 15 秒子任务，再裁成该镜头文件。
- API 失败、下载失败或 FFmpeg 切割失败均保留明确任务错误，不覆盖已存在的成功镜头。

## 视频工作台同步

- 镜头脚本列直接使用完整镜头脚本分块，每个镜头之间使用浅色分隔线。
- 脚本列独立上下滚动。
- 用户滚动到某镜头时，轨道选择同步到该镜头。
- 用户点击轨道片段时，脚本列自动滚动到对应镜头。
- 选择变化继续驱动资产匹配和视频预览。

## 设置页

- 独立设置页展示并允许修改项目的视频尺寸、清晰度和公共前缀。
- 固定模型和固定生成方式以只读说明展示，不允许用户切换。
- API 密钥只显示“已配置/未配置”，不返回密钥内容。

## 验证

- 后端测试覆盖项目配置默认值与保存、云映请求、轮询、下载、15 秒分批和 FFmpeg 切割。
- 前端测试覆盖导航直达、创建表单自动命名、设置页和脚本—轨道双向同步。
- 运行全量 pytest、Vitest、TypeScript 和生产构建，并审计 RunningHub 活跃引用。
