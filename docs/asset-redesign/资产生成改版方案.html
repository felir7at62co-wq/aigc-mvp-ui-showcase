提示词提取页移除 · 创建项目自动提取 · 资产生成卡片化重构　|　AIGC Pipeline　|　2026-07-20

1. 需求背景

  • 删掉「提示词提取」步骤页：用户在程序里创建项目后，程序自动完成角色 / 场景 / 道具的提示词提取，不再需要人工进入专门页面操作。
  • 资产生成页卡片化：剧本需要的所有资产（包括还没生成图片的）直接以卡片展示在生成结果区。未生成的卡片展示 名称 / 别名 / 出场集数 / 提示词 四项且可修改；生成后卡片为 图片 + 名称 / 别名 / 集数。
  • 添加 / 编辑 / 删除融入卡片：网格里的「+」卡片添加资产（弹面板填四项）；点开卡片编辑；鼠标悬停卡片右上角出现 × 删除。顶部「新增 / 编辑 / 删除资产」按钮和左侧名称列表随之移除。

3.2 添加资产流程

点击「＋添加资产」卡片→ 弹出编辑面板（名称 / 别名 / 集数 / 提示词）→ 保存后网格出现未生成卡片→ 点图片区选「AI 生成」或「上传图片」

名称为空或提示词为空时「AI 生成」不可用（菜单置灰并提示原因）。名称即图片文件名。

3.3 编辑资产流程

双击任意卡片→ 同一编辑面板，带入现有四项→ 保存（改名会同步改图片文件名与提示词行）

5. 自动提取设计

创建 / 打开项目→ 检查：有剧本 且 三类提示词文件都不存在→ 后台顺序提取：角色 → 场景 → 道具→ 每类完成，对应标签页卡片即时出现
  • 不重复提取：只要任一提示词文件已存在，就不自动跑；想重跑用「🔁 重新提取」。
  • 失败保护（沿用现有机制）：提取先写 .extracting 临时文件，成功才替换正式文件；失败保留已有人工校对的文本，并写 *_extraction_failed.txt 供排查。
  • 可停止：提取走统一的运行态（进度条 + 停止按钮）；切换项目自动取消未完成的提取队列。
  • 互斥：提取进行中禁止生成图片；生成进行中禁止重新提取。
  • 进度可见：资产生成页日志区实时显示提取进度与结果数量。

7. 测试与验证

7.1 自动化

  • 全量 pytest：现有 122 个用例保持全绿，另更新上述 2 个测试文件。

7.2 手动冒烟清单

  1. 新建项目 → 自动提取开始（日志有进度）→ 三类卡片陆续出现（未生成态、四项信息）
  2. 单击卡片 → 选中高亮；再单击 → 取消；全选 / 取消全选生效
  3. 生成选中 → 卡片转「生成中」→ 成功后变图片卡片（三项信息）
  4. 双击卡片 → 编辑面板改名称/提示词 → 保存后卡片与文件同步
  5. 未生成卡片点图片区 → 菜单选 AI 生成 / 上传图片，各验证一次
  6. 已生成卡片点图片区 → 查看大图 / 重新生成 / 替换图片
  7. 悬停卡片 → ×删除 → 确认后卡片、提示词行、图片、选择状态均移除
  8. 「+」卡片添加新资产 → 填四项保存 → 出现未生成卡片
  9. 重新提取 → 确认后覆盖提示词文本、图片保留
  10. 导入自定义 TXT / 编辑提取模板 在资产生成页可用
  11. 旧项目（已有提取结果）打开 → 不重复提取，直接出卡片

8. 风险与边界

风险 / 边界应对
自动提取消耗 LLM 额度（每个新项目 3 次调用）只在"三类文件全缺"时触发一次；已有结果绝不重跑
创建项目后马上切走 / 关闭程序提取在后台线程，切换项目自动取消；已完成的分类结果已落盘，下次打开直接展示
提取失败（LLM 挂 / 格式错）不覆盖已有文本；日志区给出原因；可手动「重新提取」或「导入自定义 TXT」兜底
卡片很多时网格性能缩略图按需加载（QPixmap 缩放后缓存），短剧项目资产量级（几十张）无压力
删除 × 误触确认弹窗兜底；删除范围明示（提示词行 + 图片 + 选择状态）
